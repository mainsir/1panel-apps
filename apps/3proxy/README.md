## 产品介绍

3proxy 是一款轻量、成熟的免费代理服务器，支持 HTTP/HTTPS 与 SOCKS4/5 等协议。本应用采用环境变量配置镜像，可在 1Panel 中一键安装，默认启用账号密码认证。

## 主要功能

- HTTP 代理与 SOCKS5 代理同时监听
- 安装表单配置端口、账号、密码与 DNS
- 加入 `1panel-network`，便于与面板内其他应用互通
- 配置均通过环境变量注入，便于备份与迁移

## 默认端口

| 用途 | 默认宿主机端口 | 容器端口 |
|---|---|---|
| HTTP 代理 | 3128 | 3128 |
| SOCKS5 代理 | 1080 | 1080 |

## 使用说明

安装后使用：

- HTTP：`http://用户名:密码@服务器IP:HTTP端口`
- SOCKS5：`socks5://用户名:密码@服务器IP:SOCKS端口`

> 请勿在公网暴露无认证代理。默认要求填写登录账号与密码。

## 数据目录

本方案以环境变量配置为主，无业务持久化目录。如需自定义完整 `3proxy.cfg`，可另行改用挂载配置文件方案。
