## 产品介绍

Gitea 是一款开源的轻量级自建 Git 服务。本应用采用 SQLite 单容器轻量部署方案，无需独立安装 MySQL 或 PostgreSQL 等数据库，内存占用极低（1C1G 小内存服务器亦可流畅运行），适合个人开发者与微型团队自建代码托管平台。

## 主要功能

- Git 代码仓库托管（支持 HTTP 与 SSH clone）
- 内置轻量 SQLite3 数据库，单容器免外部数据库运维
- 代码审查、工单管理（Issues）、里程碑与代码合并（Pull Requests）
- 支持内置轻量 CI/CD（Gitea Actions）
- 界面轻巧流畅，支持多语言与暗黑主题

## 默认端口

| 用途 | 宿主机默认端口 | 容器内端口 |
|---|---|---|
| Web (HTTP) | 3000 | 3000 |
| SSH (Git) | 222 | 22 |

修改安装参数中的 SSH 端口后，Gitea 展示的 SSH 克隆地址会自动使用新端口。首次安装时请在 Gitea 初始化页面填写实际访问地址；使用反向代理或修改 Web 端口后，也应同步检查 Gitea 的公开访问地址（ROOT_URL）。

## 数据目录

`./data`（包含 Gitea 配置文件、仓库数据与 `gitea.db` 数据库文件）

## 安全与升级

- 安装后请立刻打开页面完成初始化。完成前，任何能访问该端口的人都能打开安装向导，建议先用防火墙限制来源。
- 新安装默认关闭自助注册，因此必须在向导中创建管理员账号。之后可在 `data/gitea/conf/app.ini` 中调整。
- 向导里的「HTTP 服务端口」请保持 `3000`：这是容器内端口，容器启动时会强制改回。对外端口只在 1Panel 参数中修改。
- 从 1.27.x 升级到 28.x 前请先备份。28.0 调整了出站规则：`ALLOWED_DOMAINS`、`BLOCKED_DOMAINS` 和 `ALLOW_LOCALNETWORKS` 已弃用，`ALLOWED_HOST_LIST` 在默认模式下不再限制公网地址。用过这些设置，或有镜像同步、仓库迁移的，升级后请复测。
