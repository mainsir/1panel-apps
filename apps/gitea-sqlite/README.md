## 产品介绍

本应用使用 SQLite 部署单容器 Gitea，提供 Git 仓库托管、代码审查、工单和项目协作功能，无需单独部署数据库。

## 功能

- 支持 HTTP 和 SSH 仓库访问。
- 使用内置 SQLite 数据库保存应用数据。
- 提供 Pull Request、Issues 和代码审查。
- 支持 Gitea Actions；执行任务需另行配置 Runner。

## 默认端口

| 用途 | 宿主机端口 | 容器端口 |
|---|---|---|
| Web | 3000 | 3000 |
| SSH | 222 | 22 |

首次安装时，在 Gitea 初始化页面填写实际访问地址。

修改安装参数中的 SSH 端口后，Gitea 展示的 SSH 克隆地址会使用新端口。使用反向代理或修改 Web 端口后，还需检查 Gitea 的公开访问地址 `ROOT_URL`。

## 数据目录

`./data` 映射到容器的 `/data`，包含配置文件、仓库和 SQLite 数据库。初始化脚本设置 UID/GID 为 1000。升级或卸载前应备份该目录。

## 运行环境

- 镜像：`gitea/gitea:1.27.3`
- 架构：amd64、arm64
