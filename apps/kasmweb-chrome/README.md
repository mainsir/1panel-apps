## 产品介绍

Kasm Chrome 是一款运行在 Docker 中的云端独立 Chrome 桌面浏览器。通过先进的 KasmVNC WebRTC 技术，用户可直接在任意网页浏览器中以接近原生 60fps 的流畅度操作完整的 Google Chrome。

本应用支持全量数据持久化，重启容器后扩展插件、书签收藏、网站登录状态（Cookie/密码）及下载文件均可完整保留。

## 主要功能

- **WebRTC 高清低延迟**：毫秒级响应，打字与页面滚动流畅，支持视频声音音频同步播放
- **完整数据持久化**：挂载 `/home/kasm-user`，书签、配置、插件和下载文件持久保存
- **便捷控制台侧边栏**：左侧工具栏支持双向剪贴板同步、文件快速上传与下载
- **安全隔离**：独立沙箱运行，支持密码认证访问

## 默认端口与访问

| 用途 | 宿主机默认端口 | 容器内端口 | 协议 |
|---|---|---|---|
| Web 访问 | 6901 | 6901 | HTTPS |

- 访问地址：`https://服务器IP:6901`
- 默认登录用户名：`kasm_user`
- 登录密码：安装表单中填写的密码（支持随机生成）

> [!NOTE]
> 容器默认采用自签名 SSL 证书，初次通过浏览器访问时若提示“证书无效 / 不安全”，点击“高级”并“继续前往”即可正常加载。

## 数据目录

`./data`（映射容器内 `/home/kasm-user`，包含 Chrome Profile、配置文件及 `Downloads` 文件夹）
