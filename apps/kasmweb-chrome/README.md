## 产品介绍

Kasm Chrome 提供通过浏览器访问的 Chrome 桌面环境。本应用使用 KasmVNC，并将用户目录持久化到宿主机。

## 功能

- 通过 HTTPS 访问 Chrome 桌面。
- 支持剪贴板和文件传输。
- 保留用户目录中的浏览器配置、书签、扩展和下载文件。

## 访问方式

| 参数 | 默认值 |
|---|---|
| 宿主机端口 | 6901 |
| 容器端口 | 6901 |
| 协议 | HTTPS |
| 用户名 | `kasm_user` |

访问 `https://服务器IP:6901`，使用安装表单中配置的密码登录。端口修改后使用对应的新地址。

镜像默认使用自签名证书。通过域名提供服务时，可在反向代理中配置受信任的证书。默认打开的网址和时区可在安装参数中设置。

## 数据目录

`./data` 映射到 `/home/kasm-user`，包含用户配置和下载文件。初始化脚本设置目录所有者。升级或卸载前应备份该目录。

## 运行环境

- 镜像：`kasmweb/chrome:1.19.0`
- 架构：amd64
- 共享内存上限：1 GiB
