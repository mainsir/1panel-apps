## 产品介绍

EmbyProxy 是面向 Emby 的代理服务，可在 1Panel 中一键部署，支持自定义 Web 端口与管理 Token。

## 主要功能

- 安装时自定义宿主机 Web 端口
- 管理 Token 支持随机生成
- 数据持久化到 `./data`，便于备份迁移
- 使用桥接网络 + `1panel-network`（**不是 host 模式**）

## 默认端口

| 用途 | 默认宿主机端口 | 容器端口 |
|---|---|---|
| Web | 8787 | 8787（固定） |

安装时可把宿主机端口改成任意空闲端口，例如 `9877` → 访问 `http://服务器IP:9877`。

## 网络说明

- **模式**：bridge（端口映射）
- **网络**：`1panel-network`（external）
- **不是** `network_mode: host`

容器内服务固定监听 `8787`，对外只暴露你在表单里填的宿主机端口。

## 数据目录

`./data`（含 `proxy.db` 等运行数据）
