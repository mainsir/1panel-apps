## 产品介绍

本应用基于 sing-box 提供 VLESS over TCP 入站服务，使用 Reality TLS 和 `xtls-rprx-vision`。支持 IPv4、IPv6，以及可选的 SOCKS5 出口代理。

## 默认参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| 监听端口 | 38443 | 使用 host 网络，直接监听宿主机端口 |
| SNI | www.nvidia.com | Reality 握手目标，使用该域名的 443 端口 |
| 客户端指纹 | chrome | 写入客户端分享链接 |
| 出口代理 | 留空 | 留空时直接访问目标服务器 |

## 使用说明

1. 在安装表单中设置监听端口、SNI 和客户端连接地址。连接地址填写 IP 或域名，不包含协议、端口或路径。
2. 启动后从数据目录的 `client.txt` 获取客户端参数和分享链接。连接地址留空时，需手动替换链接中的 `<服务器IP>`。
3. IPv6 地址会自动添加方括号。IPv6 访问还要求宿主机具有可达的 IPv6 地址，且防火墙允许相应端口。
4. 配置出口代理时，SOCKS5 地址与端口须同时填写；启用认证时，账号与密码须同时填写。
5. 修改参数后，容器启动时重新生成运行配置，已有节点密钥保持不变。

## 密钥与升级

首次启动生成 UUID、Reality 密钥对和 short ID，校验配置后保存为 `keys.env`。已有文件只读取；内容缺失或格式无效时启动失败，不自动更换身份。出现错误时应从备份恢复密钥文件。

应用包 `1.0.2` 修复了密钥写入和 IPv6 监听行为，镜像版本仍为 `v1.13.14`。已有实例请先备份 `data` 目录，再通过 1Panel 升级；有效的旧版密钥可继续使用。

卸载可能删除实例目录。保留原客户端配置时，重装前应恢复原 `keys.env`。

## 数据目录

| 路径 | 内容 |
|---|---|
| `./data/keys.env` | UUID、Reality 密钥对和 short ID |
| `./data/config.json` | 经校验后发布的运行配置 |
| `./data/client.txt` | 客户端参数和分享链接 |

## 运行环境

- 镜像：`ghcr.io/sagernet/sing-box:v1.13.14`
- 架构：amd64
- 网络：host，监听地址 `::`，提供 IPv4/IPv6 TCP 服务
